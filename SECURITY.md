# Security policy

Do not place exploit details, access tokens, credentials or personal documents in
public issues. Enable GitHub private vulnerability reporting for this repository
before accepting community releases. Until that channel is enabled, this starter
does not claim an operational incident-response service.

Listing presence is not approval. Approval applies to one immutable release and
every included app/extension/widget/recipe under a recorded policy revision.
Each new version requires automated qualification before approved publication.
Checks reduce risk; they do not guarantee zero vulnerabilities or safe behavior.

Revoked code is disabled with a recovery/export path; removal must preserve user
data by default. Marketplace implementation and sensitive investigation records
are maintained outside this public package repository.
